Subnet Chart — step by step

Use this for any "fill in the chart" question. Example: 172.16.62.68/26

  1. Turn the prefix into a mask. The prefix is how many 1s there are. Every 8 ones = 255. Leftover ones go in the next octet, adding from the left: 1→128, 2→192, 3→224, 4→240, 5→248, 6→252, 7→254.
    /26 = 8+8+8+2 → 255.255.255.192
  2. Copy the 255 octets. Wherever the mask is 255, the IP copies straight down into every answer. Find the interesting octet: the one that isn't 255 or 0. That's the only octet you work on.
    Answers all start 172.16.62. — only work on the .68
  3. Find the increment. Increment = 256 − interesting octet. (It's also the place value of the last 1 bit in the mask.)
    256 − 192 = 64
  4. List the subnets. Start at 0 and keep adding the increment. Stop before 256.
    0, 64, 128, 192
  5. Round down. Find the subnet your IP falls in: the one at or just below the IP's number.
    68 is past 64 but not at 128 → subnet .64
  6. Fill in the chart.
    BoxHowExample
    Networkthe rounded-down subnet.64
    Broadcastnext subnet − 1128−1 = .127
    Gatewaynetwork + 1.65
    Last usablebroadcast − 1.126
    Usable hosts2h − 2, h = 32 − prefix2⁶−2 = 62

Answer

Network 172.16.62.64 · Gateway .65 · Last usable .126 · Broadcast .127 · 62 hosts

Steps 3 and 4 do most of the work. Once you have the increment and the subnet list, the rest is just +1 and −1.

ANDing — finding the network address

Example: 10.103.166.35 with mask 255.255.255.252 (/30)

  1. Copy the 255 octets. Anything under a 255 copies straight down; anything under a 0 becomes 0.
    → 10.103.166.___
  2. Convert the interesting octet of both the IP and the mask to binary. (See "Binary" below.)
    35 = 00100011 · 252 = 11111100
  3. AND them column by column. The result is 1 only where both are 1. Anything over a 0 becomes 0. 
    IP    00100011  (35)
Mask  11111100  (252)
      --------
AND   00100000  (32)
  4. Convert back to decimal and put it in the blank.
    → 10.103.166.32

Shortcut to check your answer

Increment = 256 − 252 = 4. Subnets go …28, 32, 36… 35 rounds down to 32. ANDing and rounding down always give the same answer.
The "round down" rule

The network is always the subnet number at or below your IP: round down to the nearest multiple of the increment.

This works because each subnet runs from its own number up to just before the next one. With increment 4: .32 covers .32–.35 and .36 covers .36–.39, so .35 can only be in .32.

Lands exactly on a subnet number? Then that is the network. Nothing rounds down. That address is the network address itself, so a host can't use it.

Decimal → binary (subtract method):

  1. Start at 128.
  2. If your number is ≥ that place value, write 1 and subtract it. Otherwise write 0.
  3. Move to the next place value (64, 32, …) and repeat until you've done all 8.

Example: 35

128? no 0 · 64? no 0 · 32? yes 1 (35−32=3) · 16 0 · 8 0 · 4 0 · 2? yes 1 (3−2=1) · 1? yes 1 → 00100011

Binary → decimal: add up the place values wherever there's a 1.

Prefix ↔ mask

Prefix → mask: write that many 1s, then 0s to fill 32 bits. Each full octet of 1s = 255, each full octet of 0s = 0. The partial octet comes from the list below.

Mask → prefix: each 255 = 8. Then add the 1s in the partial octet.

Formulas
  1. Usable hosts per subnet = 2h − 2, where h = host bits = 32 − prefix. (You lose the network and broadcast addresses.)
    /27 → h = 5 → 32 − 2 = 30
  2. Number of subnets = 2n, where n = bits borrowed. The new prefix = old prefix + n.
    /24 borrow 3 → 2³ = 8 subnets, /27
  3. "I need X hosts": find the smallest h where 2h − 2 ≥ X. Prefix = 32 − h.
    50 hosts → 2⁵−2 = 30 ✗, 2⁶−2 = 62 ✓ → /26
  4. "I need N subnets": find the smallest n where 2n ≥ N. Add n to the prefix.
    5 subnets from /24 → 2²=4 ✗, 2³=8 ✓ → borrow 3 → /27
  5. Network increment = 256 − the interesting mask octet.
    255.255.255.240 → 256 − 240 = 16

Stretch mode (prefixes under /24)

Same steps, but the interesting octet moves left. Rule: every octet after the interesting one becomes 0 for the network and 255 for the broadcast.

Example: 172.16.62.68/22

Mask 255.255.252.0 → interesting octet is the 3rd
Increment 256 − 252 = 4 → subnets 0, 4, … 56, 60, 64…
62 rounds down to 60 → Network 172.16.60.0
Next subnet is .64, so Broadcast = 172.16.63.255
Gateway 172.16.60.1 · Last usable 172.16.63.254 · 2¹⁰−2 = 1022 hosts
